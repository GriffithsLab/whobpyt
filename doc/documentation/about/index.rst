About the WhoBPyT Library
=========================

WhoBPyT (Whole-Brain Modelling in PyTorch) is a Python library for building
connectome-based models of large-scale brain dynamics and fitting them to
neuroimaging and neurophysiology data, such as EEG, MEG and TMS-EEG.
