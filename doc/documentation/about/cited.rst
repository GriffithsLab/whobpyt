Papers using WhoBPyT
====================

A full list of papers that use WhoBPyT is in preparation.

In the meantime, the :ref:`examples gallery <examples-gallery>` contains
step-by-step replications of the modelling in several published studies from
our group, including:

* Momi D, Wang Z, Griffiths JD. TMS-evoked responses are driven by recurrent
  large-scale network dynamics. *eLife* (2023).
  `doi:10.7554/eLife.83232 <https://doi.org/10.7554/eLife.83232>`__
* Momi D, ..., Griffiths JD. Stimulation mapping and whole-brain modeling
  reveal gradients of excitability and recurrence in cortical networks.
  *Nature Communications* 16, 3222 (2025).
  `doi:10.1038/s41467-025-58187-6 <https://doi.org/10.1038/s41467-025-58187-6>`__

If you have published work that uses WhoBPyT, please let us know by
`opening an issue on GitHub <https://github.com/GriffithsLab/whobpyt/issues>`__
so we can add it here.
