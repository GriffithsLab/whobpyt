Papers using WhoBPyT
====================

A full list of papers that use WhoBPyT is in preparation.

In the meantime, the :ref:`examples gallery <examples-gallery>` contains
step-by-step replications of the modelling in several published studies from
our group, including Momi, Wang & Griffiths,
`eLife 2023 <https://doi.org/10.7554/eLife.83232>`__.

If you have published work that uses WhoBPyT, please let us know by
`opening an issue on GitHub <https://github.com/GriffithsLab/whobpyt/issues>`__
so we can add it here.
